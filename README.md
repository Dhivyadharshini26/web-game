# Memory Card Matching Game

A simple and interactive Memory Card Matching Game developed using HTML, CSS, and JavaScript. The game challenges users to find matching card pairs by flipping two cards at a time.

---

## 🚀 Features

* Interactive card flip functionality
* Random card shuffle on every game start
* Matching card detection
* Shake animation for incorrect matches
* Responsive design for desktop and mobile devices
* Automatic game reset after all pairs are matched

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

1. Download or clone the repository
2. Open the project folder
3. Run the `index.html` file in your browser

---

## 🎮 How to Play

1. Click on a card to flip it
2. Flip another card to find the matching pair
3. If both cards match, they remain open
4. If they do not match, they flip back automatically
5. Match all pairs to complete the game

---

## 📸 Game Functionality

* Users can flip only two cards at a time
* Matching cards stay visible
* Non-matching cards shake and flip back
* Cards are shuffled randomly for every new game
